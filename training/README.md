# Обучение разговорной модели Helio

Этот набор готовит и дообучает русскоязычный разговорный адаптер Helio Gen 1 на открытых весах Qwen3-1.7B. Базовая модель уже знает языки и общие темы; QLoRA учит её лучше вести многоходовой диалог в нужном для Helio стиле. Это не pretraining модели с нуля.

## Запуск в бесплатном Google Colab

1. Открой [ноутбук Helio Train в Colab](https://colab.research.google.com/github/ooaoooa4562-beep/aimachine/blob/main/training/Helio_Train.ipynb).
2. Выбери **Runtime → Change runtime type → T4 GPU**, если бесплатный GPU доступен.
3. Нажми **Runtime → Run all**. Первый шаг загрузит примерно несколько гигабайт базовых весов и русский корпус OpenAssistant.
4. Ноутбук попросит подключить Google Drive, чтобы сохранить адаптер и checkpoint-и при завершении сессии.

Бесплатный Colab не обещает GPU каждому запуску, а доступные ускорители и длительность сессии меняются. Если GPU временно недоступен, попробуй позже; обучение на этой локальной машине не подойдёт, потому что в ней нет CUDA GPU.

## Что войдёт в данные

- Русские ветки проверенного корпуса [OpenAssistant/oasst1](https://huggingface.co/datasets/OpenAssistant/oasst1), лицензия Apache-2.0. Скрипт восстанавливает контекст до каждого ответа, убирает удалённые/плохо оценённые записи и строки с пометкой о персональных данных.
- Небольшая вручную написанная выборка Helio в `data/helio_train.jsonl` и `data/helio_validation.jsonl`. Она показывает дружелюбный тон, переключение тем и помощь с учёбой. Это стартовые примеры, не достаточный корпус для обучения с нуля.

Подготовка пишет данные только в `training/output/dataset/`. Веса модели и адаптеры не добавляются в Git.

## Локальный запуск на машине с NVIDIA GPU

В окружении с CUDA установи зависимости и запусти:

```bash
pip install -r training/requirements.txt
python training/prepare_oasst.py
python training/train.py
```

Открой `training/train.py`, чтобы изменить базовую модель, число эпох, длину контекста и параметры обучения. По умолчанию полученный PEFT-адаптер сохраняется в `training/output/helio-gen1-lora/`.

## Ограничения

Дообучение меняет стиль и примеры поведения, но не превращает небольшую модель в безошибочного эксперта. Для точных вычислений Helio по-прежнему должен вызывать SymPy. Этот адаптер пока не подключён к сайту: обучение создаёт веса, а их запуску в веб-приложении потребуется отдельный inference-сервис или запуск на устройстве.

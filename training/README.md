# Обучение Helio Gen 1 с нуля

Файл train.py создаёт русскоязычную небольшую GPT-модель со случайно инициализированными весами. Она не загружает Qwen или другую готовую языковую модель и не использует чужие веса. Архитектура и инструменты PyTorch/Transformers помогают собрать нейросеть, а сами веса и BPE-токенизатор Helio обучаются на выбранных диалогах.

## Бесплатное обучение в Google Colab

Открой [ноутбук обучения Helio в Google Colab](https://colab.research.google.com/github/ooaoooa4562-beep/aimachine/blob/main/training/Helio_Train.ipynb), выбери **Среда выполнения → Сменить тип среды выполнения → T4 GPU**, затем запускай ячейки по порядку. Colab может временно не выдать бесплатный GPU; если так случится, попробуй позже.

Ноутбук:

1. устанавливает библиотеки для обучения и ONNX;
2. собирает русские диалоги OpenAssistant и вручную подготовленные примеры Helio;
3. учит Flash с нуля и сохраняет веса на Google Drive;
4. экспортирует Flash в ONNX и создаёт INT8-вариант для браузера;
5. упаковывает браузерную модель, которую можно скачать и добавить в web/models/helio-gen1-flash/.

Для Pro выставь HELIO_VARIANT=pro в Colab и запусти обучение и экспорт ещё раз. Pro крупнее и дольше учится, но не становится автоматически умной: качество зависит от объёма и качества данных.

## Важно про качество

Это экспериментальная компактная модель, а не аналог ChatGPT. Она учится предсказывать продолжение текста на сравнительно небольшом наборе диалогов, поэтому её первые ответы могут быть простыми, повторяться или ошибаться. Для содержательного общения с нуля нужны намного большие очищенные русскоязычные данные и продолжительное обучение на GPU. Символьную точность математических задач продолжает обеспечивать SymPy; генеративная модель не должна подменять точные вычисления.

Модель получает примеры дружелюбного разговора, поддержки без пустой лести и естественного переключения тем. Для школьного приложения допускаются только лёгкие слова вроде «блин» или «капец» — без грубых ругательств, оскорблений, травли и угроз.

## Локальный запуск на машине с NVIDIA GPU

Нужен Python с поддерживаемой PyTorch версией и NVIDIA CUDA. Python 3.14 и компьютер без CUDA GPU, который сейчас используется для проекта, для обучения не подходят.

Установи зависимости командой: pip install -r training/requirements.txt

Подготовь данные: python training/prepare_oasst.py

Обучи Flash: HELIO_VARIANT=flash python training/train.py

Экспортируй Flash: HELIO_VARIANT=flash python training/export_browser_model.py

В Windows PowerShell перед командами задай: $env:HELIO_VARIANT = "flash"

Экспортируемые файлы появятся в web/models/helio-gen1-flash/. Их нужно добавить в репозиторий и опубликовать сайт. До появления этих файлов интерфейс честно сообщает, что собственная модель ещё не добавлена; сетевой поиск чужих весов отключён.

## Данные

- prepare_oasst.py собирает русские ветки диалогов из [OpenAssistant/oasst1](https://huggingface.co/datasets/OpenAssistant/oasst1), отбрасывает удалённые и отмеченные записи и смешивает их с локальным набором Helio.
- data/helio_train.jsonl и data/helio_validation.jsonl содержат написанные для Helio разговорные примеры. Их можно расширять, проверяя, что в них нет личных данных.
- Сырые веса, checkpoint-и и подготовленные большие корпуса не коммитятся в Git. Браузерные веса нужно распространять отдельно от исходников или добавить в GitHub Pages, если размер репозитория это позволяет.

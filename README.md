# Умная школа

Android-приложение школьного помощника по математике. Есть выбор класса, новые чаты, локально сохранённая история и переключение режимов Helio Gen 1 Flash / Pro. Встроенный математический движок считает арифметические выражения со скобками, степенями, функциями sin/cos/tan, ln/log, квадратными корнями, решает линейные и квадратные уравнения и распознаёт отдельные задачи на площадь круга и параметры квадрата.

## Режимы Helio

Flash и Pro пока являются режимами интерфейса, а не отдельными обученными ML-моделями: математические вычисления выполняет локальный движок. Для подключения настоящих генеративных моделей нужен backend и отдельный этап обучения/интеграции.

## APK

GitHub Actions собирает APK при каждом push в `main`. Открой вкладку **Actions**, выбери последний запуск **Build Android APK** и скачай артефакт `school-ai-debug-apk`.

## Важно

Это стартовый интерфейсный прототип, не готовый ИИ и не обученная с нуля модель. Решатель намеренно ограничен простыми уравнениями. Следующий этап — добавить проверяемые математические алгоритмы и учебные данные, затем разрабатывать небольшую ML-модель.

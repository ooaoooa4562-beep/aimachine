# Умная школа

Android-приложение школьного помощника по математике. Есть выбор класса, новые чаты, локально сохранённая история, голосовой ввод и переключение режимов Helio Gen 1 Flash / Pro. SymPy встроен в приложение с помощью Chaquopy и работает локально на устройстве. Он разбирает выражения, уравнения, степени, тригонометрию, производные, интегралы и некоторые задачи геометрии.

## Режимы Helio

В веб-версии Flash и Pro предназначены для собственных весов Helio. Разговорная модель строится с нуля на PyTorch и случайной инициализации, без готовых весов Qwen. Пока обученные ONNX-файлы не добавлены в web/models, свободная беседа недоступна; SymPy продолжает решать поддерживаемые математические задачи. Подробности и ноутбук для бесплатного обучения в Colab находятся в training/README.md. В Android APK свободная беседа пока не подключена.

## Обновления приложения

Каждая успешная сборка публикуется как GitHub Release. Приложение периодически проверяет последний релиз и предлагает скачать APK. Android требует подтвердить установку в системном установщике и разрешить установку из этого источника.

## Веб-версия

Веб-версия Helio находится в папке web и публикуется через GitHub Pages после изменений в ней. Она использует Pyodide и SymPy для точных вычислений. После обучения и добавления ONNX-весов в web/models разговорная модель будет генерировать ответы в браузере без загрузки чужих весов. История хранится на устройстве; можно создавать новые чаты, копировать ответ и просить модель ответить ещё раз. Веб-голосовой ввод доступен в браузерах с Web Speech API, например Chrome и Edge; распознанный текст можно поправить перед отправкой. Открой https://ooaoooa4562-beep.github.io/aimachine/ и добавь страницу на главный экран планшета; изменения сайта появятся после перезагрузки страницы без переустановки APK.

## APK

GitHub Actions собирает APK при каждом push в `main`. Открой вкладку **Actions**, выбери последний запуск **Build Android APK** и скачай артефакт `school-ai-debug-apk`.

## Важно

Обученная с нуля модель будет экспериментальной и заметно слабее больших чат-ботов, пока у неё мало данных и параметров. Она не должна заменять точные математические вычисления SymPy.

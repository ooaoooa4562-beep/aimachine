# Умная школа

Android-приложение школьного помощника по математике. Есть выбор класса, новые чаты, локально сохранённая история, голосовой ввод и переключение режимов Helio Gen 1 Flash / Pro. SymPy встроен в приложение с помощью Chaquopy и работает локально на устройстве. Он разбирает выражения, уравнения, степени, тригонометрию, производные, интегралы и некоторые задачи геометрии.

## Режимы Helio

В веб-версии Flash запускает Qwen3-0.6B, а Pro — Qwen3-1.7B через Transformers.js и ONNX Runtime Web. Модели скачиваются из Hugging Face и выполняются в браузере на устройстве: сервер и API-ключ не нужны. Первый запуск занимает около 570 МБ для Flash или 1,43 ГБ для Pro; браузер кэширует загруженные файлы. Устройство и браузер должны иметь достаточно памяти, а для первой загрузки нужен интернет. Это готовые открытые веса Qwen3, а не собственная обученная модель Helio. В Android APK свободная беседа пока не подключена.

## Обновления приложения

Каждая успешная сборка публикуется как GitHub Release. Приложение периодически проверяет последний релиз и предлагает скачать APK. Android требует подтвердить установку в системном установщике и разрешить установку из этого источника.

## Веб-версия

Веб-версия Helio находится в папке web и публикуется через GitHub Pages после изменений в ней. Она использует Pyodide и SymPy для точных вычислений, а выбранная разговорная модель генерирует ответы постепенно в браузере. История хранится на устройстве; можно создавать новые чаты, копировать ответ и просить модель ответить ещё раз. Веб-голосовой ввод доступен в браузерах с Web Speech API, например Chrome и Edge; распознанный текст можно поправить перед отправкой. Открой https://ooaoooa4562-beep.github.io/aimachine/ и добавь страницу на главный экран планшета; изменения сайта появятся после перезагрузки страницы без переустановки APK.

## APK

GitHub Actions собирает APK при каждом push в `main`. Открой вкладку **Actions**, выбери последний запуск **Build Android APK** и скачай артефакт `school-ai-debug-apk`.

## Важно

Это стартовый интерфейсный прототип, не готовый ИИ и не обученная с нуля модель. Решатель намеренно ограничен простыми уравнениями. Следующий этап — добавить проверяемые математические алгоритмы и учебные данные, затем разрабатывать небольшую ML-модель.
